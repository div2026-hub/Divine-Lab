# Linux Fundamentals

## Commands Learned

### pwd
Print Working Directory.
Shows the current location of the user in the Linux file system.

### ls
Lists files and directories in the current location.

### ls -la
Lists all files, including hidden files, with detailed information such as permissions, owner, and date.

### cd
Change Directory.
Used to move from one directory to another.

### mkdir
Make Directory.
Used to create a new folder

### cp
Copy files from one location to another.

### mv
Move or rename files.

### cat
Displays the contents of a file.

### touch
Creates a new empty file..
